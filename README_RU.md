# Don't delete my apps

Экспериментальный Android-проект на Kotlin. Min SDK 26, target SDK 35. Нужны JDK 17 и Android SDK Platform 35.

## Возможности
- AMOLED-интерфейс и предоставленная иконка.
- PIN-код (в настройках хранится SHA-256-хеш).
- Список установленных приложений и выбор защищаемых.
- Accessibility Service отслеживает некоторые окна системного установщика.
- При совпадении названия защищённого приложения служба закрывает текущий экран подтверждения и показывает PIN-окно.
- После правильного PIN защита снимается для этого приложения; удаление нужно повторить вручную.

## Ограничения
Это экспериментальная защита, а не системная блокировка удаления. Служба распознаёт только доступные ей окна и текст. Разные версии Android/HyperOS используют разные установщики и формулировки. ADB, безопасный режим, некоторые системные экраны или отключение Accessibility Service могут обойти защиту. Не используй её как единственную защиту важных данных.

## Сборка и запуск
1. Открой папку проекта в Android IDE / Code Assist.
2. Синхронизируй Gradle (JDK 17).
3. Собери APK.
4. Открой приложение, задай PIN и выбери приложения.
5. Нажми «Включить службу специальных возможностей».
6. В системных настройках включи службу Don't delete my apps.
7. Проверь на тестовом приложении, которое не жалко переустановить.

`QUERY_ALL_PACKAGES` нужен для отображения списка установленных приложений. В Google Play его использование ограничено политикой магазина; проект ориентирован на личную установку.
